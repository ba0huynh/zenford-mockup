Zen, mèo robot của Zenford: đầu trắng tai vàng, mặt màn hình đen, mắt LED vàng, viền ink. Mỗi file một biểu cảm hoặc một bộ đồ; nền trong suốt.

- Biểu cảm (áo theo pastel): `zen-binh-thuong` (normal), `zen-vui` (happy), `zen-bat-ngo` (wow), `zen-nhay-mat` (wink), `zen-suy-nghi` (think), `zen-thich` (love), `zen-buon` (sad), `zen-quyet-tam` (fierce, áo choàng coban).
- Bộ đồ: `zen-tay-dua` (mũ bảo hiểm, chủ đề đường đua), `zen-dau-tivi` (ăng-ten, thông báo và tin tức), `zen-lab-nghe` (tai nghe), `zen-lab-noi` (micro), `zen-lab-doc` (sách), `zen-lab-viet` (bút chì).
- Trên web nên dựng Zen bằng `ZenfordNP.zenSVG(state, hood, outfit)` để mắt nhìn theo con trỏ và chớp; file SVG dùng cho ấn phẩm, slide, mạng xã hội.
